# Luxwap 客户端使用与帮助指南

> 适用版本：Luxwap Desktop 2.0+ (Windows / macOS)

---

## 1. 产品简介
Luxwap 是一款跨平台的高性能网络代理客户端，支持 Windows 10/11 与 macOS（Intel / Apple Silicon 芯片双架构）。客户端内置 `luxwap_core` 高性能网络传输核心，提供高匿名性、弹性并发与稳定可靠的网络连接体验。

---

## 2. 快速入门

### 2.1 登录与注册
1. 打开 Luxwap 客户端。在主卡片上方可通过 **「账号登录」** 与 **「账号注册」** 标签无缝切换。
2. 注册账号：输入有效电子邮箱、设置密码，点击「验证邮箱」获取 6 位数字验证码，完成验证后即可登录。
3. 第三方授权登录：支持通过 Google、X（Twitter）、Facebook 账户一键安全快捷授权登录。

### 2.2 选择线路与一键连接
1. 登录成功后进入 **「线路选择」** 界面。
2. 节点拥堵状态直观可视：
   - 🟢 **绿色**（负载 < 60%）：网络通畅，延迟低，推荐优先连接。
   - 🟡 **黄色**（60% ≤ 负载 ≤ 85%）：网络负载适中。
   - 🔴 **红色**（负载 > 85%）：网络繁忙，建议避开。
3. 点击任意线路卡片，窗口保持固定不抖动，顶部状态栏显示所选节点名称。
4. 点击顶部右侧「连接开关」，状态栏变绿并实时显示网络上下行速率即代表连接成功。

## 3. 核心功能与配置说明

### 3.1 路由策略与分流
在「系统设置」-「路由配置」中支持精细化分流：
- **直连本国 IP**：访问境内服务器不经过代理，保障访问速度与国内服务正常使用。
- **直连中国域名**：基于 GeoSite 精准识别国内知名域名，自动分流直连。
- **直连局域网 IP / 域名**：保障本地打印机、NAS 及局域网服务不受代理干扰。
- **阻断广告**：内置广告过滤规则，拦截常见恶意追踪与弹窗广告。

### 3.2 DNS 与 DoT (DNS over TLS)
- **DoT (DNS over TLS)**：通过 TLS 协议加密 DNS 解析请求（例如：`tcp://1.1.1.1:853`），防止本地网络运营商（ISP）的 DNS 劫持与域名污染。
- **分流 DNS**：支持针对境内流量使用国内快速 DNS（如 `223.5.5.5`），针对域外流量使用加密国际 DNS（如 `8.8.8.8`）。

### 3.3 TUN 模式 (虚拟网卡)
- 默认开启。在系统底层创建轻量级 TUN 虚拟网卡，自动接管全系统所有进程（包括不遵循系统 HTTP 代理设置的应用、命令行工具与游戏）的网络流量。

### 3.4 解除 Win10/11 UWP 应用回环限制 (Windows 专享)
Windows 操作系统默认沙盒机制限制了 UWP 应用（如 Windows 应用商店、邮件、Netflix 等）访问本地回环网络（`127.0.0.1`）。
在「设置」-「常规与系统设置」中，点击 **「解除 UWP 应用回环限制」** 按钮，客户端将自动一键完成豁免配置，恢复商店应用的网络代理。

### 3.5 系统托盘与后台常驻
- 客户端支持最小化至任务栏右下角系统托盘（Windows）或状态栏（macOS）。
- 点击关闭 (X) 按钮选项：可在设置中选择「最小化到托盘」或「直接退出」。
- 右键点击托盘图标支持快捷菜单：
  1. 打开主界面
  2. 快捷选择线路
  3. 切换代理开关（使用代理 / 停止代理）
  4. 设置关闭按钮动作
  5. 安全退出客户端

## 4. 常见问题排查 (FAQ)

### Q1: 退出客户端后，浏览器无法上网（报代理错误）怎么办？
**解答**：Luxwap 具有内置底层系统代理安全守护机制。无论正常退出、点击托盘退出、还是点击右上角关闭，客户端均会自动还原系统代理状态（清除 `ProxyServer` 并将 `ProxyEnable` 置为 0）。如因系统意外断电导致代理未清除，可重新打开客户端点击断开，或在设置中点击系统代理还原。

### Q2: 切换线路时界面窗口出现抖动或缩放？
**解答**：新版已彻底解耦窗口几何尺寸同步逻辑，仅在登录状态切换时自适应视窗，点选线路与节点测速不再触发布局跳动。

### Q3: 高分辨率（4K / 2K）屏幕上客户端字体显示过小或卡片重叠？
**解答**：新版已针对 Windows 缩放比例（125%、150%、200% DPI）完成原生物理像素缩放适配，字体尺寸已放大优化，各功能卡片支持自适应网格排列。
